# FedAttn reproducibility code

Code and compact demos accompanying **“Federated attention for collective intelligence in large language models.”**

| Experiment | Contents | Instructions |
|---|---|---|
| Mathematical reasoning on GSM8K | Inference, evaluation, system cost, and representation fidelity | [Mathematical reasoning](mathematical_reasoning/README.md) |
| Cooperative driving | Inference, evaluation, and fidelity | [Cooperative driving](cooperative_driving/README.md) |

Each experiment directory contains its own entry points and saved demo outputs. The experiment READMEs identify the processed files used for plotting, their units and the demo coverage. Compact demos illustrate the processing pipelines and are not substitutes for the full experimental results.

Model weights and driving assets must be obtained separately. Follow the environment and asset instructions for each experiment, and use a new output directory when changing settings or source code. Third-party licence files and the cooperative-driving distribution notice are retained with their corresponding components.
